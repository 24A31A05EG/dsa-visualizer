# DSA Visualizer

A web-based Data Structures and Algorithms Visualizer built using HTML, CSS, and JavaScript.

## Features

- Bubble Sort Visualization
- Binary Search Visualization
- Linked List Visualization
- Stack Visualization
- Queue Visualization
- Interactive UI

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Clone the repository
2. Open `index.html` in your browser
